# Before you run Prove It or Fail It

The skill sizes a growth test from your own numbers, locks what counts as a win, and calls the verdict at day 30. It cannot size a test on numbers you do not have. This page covers what has to be in place.

## What do I need to run it at all?

- **A Claude account on any plan, Free included,** with code execution turned on. Skills do not run without it.
- **The skill uploaded.** In Claude: Customize > Skills > + > Create skill > Upload a skill.
- **One idea.** One change you want to test.

No connectors or MCP servers are needed. Nothing is sent anywhere else.

## What must I know before the design?

| Required | Why the skill needs it |
|---|---|
| The idea, in one sentence | The rubric checks it is one change |
| The one metric it should move | The test reads one number |
| Today's baseline, last 90 days | Every lift is measured from it |
| Volume in 30 days (rates only) | Sets the smallest lift the test can see |
| Split or before and after | Sets the math and the bar |
| Budget | Sets the payback lift |
| The lift you expect | Sets the Too small to read line |
| Launch date | Sets every read date |
| One action per verdict | Locked on the card, quoted at every read |

Optional: the value of one unit (ties the test to money), the share of the audience in the test, owners.

**Before and after only:** the metric for each of the last 12 weeks. Rates need conversions and volume per week. Counts need the count per week.

## What must I have at each read?

| Read | What to bring |
|---|---|
| Day 15 | The results so far: conversions and volume per arm for a rate, the count per arm for a count |
| Day 30 | The same, for the full 30 days |
| End of an Extend | The same, for the whole run, plus the day-30 read that called Extend |
| Every read | The sealed test card |

## What makes the answer trustworthy?

| What has to be true | Why it matters | What you see if it is not |
|---|---|---|
| Chance or a fixed rule decides who sees the change | Otherwise the verdict measures who was picked | The Clean split check fails |
| The metric is counted the same way as the baseline | A new definition is a new metric | Nothing. Check before launch |
| Nothing else changes for the test group | One change, one answer | The One change check fails |
| You read only on the card's dates | Peeking and stopping on a good day inflates flukes | Nothing. The card lists the dates |
| The card is not edited | The verdict must use the numbers agreed before launch | Read refuses and names what changed |

## Readiness checklist

- [ ] Code execution is on in Claude
- [ ] The skill is uploaded
- [ ] One idea, one change
- [ ] One metric, a rate or a count, tracked today
- [ ] The baseline from the last 90 days
- [ ] 30-day volume, or 12 weeks of history for before and after
- [ ] Budget and the lift you expect
- [ ] An action agreed for each verdict

All eight are required.
